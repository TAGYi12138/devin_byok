# Devin BYOK Bridge

Devin BYOK Bridge（自用版）- 把模型请求路由到你自己的 OpenAI 兼容或 Anthropic 原生 API 供应商（已移除在线更新）

## 项目说明

这是一个 VS Code 扩展，用于将 Devin 的模型请求路由到用户自己的 OpenAI 兼容或 Anthropic 原生 API 供应商。

## 版本

当前版本：1.0.106

## 使用方法

1. 安装扩展
2. 在 VS Code 设置中配置 API 供应商地址
3. 重启 VS Code 即可使用
