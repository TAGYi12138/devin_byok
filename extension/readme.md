# Devin Model Gateway

云端发行版 1.5.0 配合业务服务 0.7.0 支持服务档位与价格版本。每张额度卡独立指定档位、模型范围和有效期，抽屉中可查看计费说明与模型倍率；同一个前端模型会根据当前卡使用对应路线。切卡不会改变已发出的请求，也不会自动跨卡借用余额。服务端缺失档位目录信息时，插件停止使用该卡的模型绑定，避免走错来源。

当前源码包含 Devin 普通版与 Next 的 3.10、3.11 系列共 23 个 Windows x64 构建的 Editor 和 Sessions 原生模型菜单适配，具体离散版本见 [兼容版本与测试说明](native-picker-compatibility.md)。安装时结合版本、提交、通道和实际代码自动选择方案，恢复会话模型选择和发送前的路由关联。SSH 空白会话的模型入口及首次连接初始化保留，普通版远端配置写入 `.devin-server`，Next 写入 `.devin-server-next`。模式的选项、标识和默认值继续使用 Agent 返回的配置。安装后重新加载窗口，并断开、重新连接 SSH；首次更新远端注册表和环境后按提示再次重连。

两个发行通道使用独立的精确匹配规则，匹配失败时不写入菜单文件。回归测试读取本机两个通道的真实界面代码，覆盖模型切换、新建会话、快速连续选择、目录刷新和发送前关联；安装测试在临时副本中检查语法、校验和、失败回滚、重复安装和完整卸载。普通版使用其自身的 ClientModelConfig 解码类，不能直接沿用 Next 的混淆名称。

SSH 首次连接通过解析器传入的实际 authority 关联当前窗口；未打开文件夹时，从远端进程 UID 和用户表读取用户目录，再同步证书、代理环境和 ACP 注册表。初始化复用正在执行的任务，随后打开文件夹也会再次检查。不会关闭 TLS 证书验证，或把固定的 Plan/Code 选项当作 Agent 的模式。

## 1.1.46 本地版独立运行

本地版不连接业务服务器：停用在线更新和图片运行库下载，图片处理库重新随本地VSIX提供；手动点击检查更新只提示使用离线安装包。手动配置API、原生模型菜单、23个具体构建适配、SSH和会话同步修复保留。云端发行版独立打包，继续使用其自己的更新与资源服务。本地安装包因此恢复约10.5MB。

## 1.1.45 插件在线更新（历史版本，已由1.1.46移除本地服务器依赖）

启动约15秒后及每6小时自动检查本地版对应的更新通道，默认后台下载并验证新版本。更新清单必须通过内置 Ed25519 公钥验证，安装包必须符合 SHA256、大小、扩展标识、版本和发行版要求；拒绝降级或把本地版换成云端版。用户点击“立即安装”才安装，然后提示重载。可在设置关闭自动检查或后台下载；命令面板提供“检查插件更新”。需要先部署业务服务0.7.4和签名发布文件，旧版首次升级仍需手动安装一次。

## 1.1.36 Remote SSH 连接前准备修复

连接前的 BYOK 准备命令超过 1.5 秒未完成时，继续正常 SSH 连接，不再无限等待；超时和命令失败路径不调用原生 SSH 日志器未提供的方法。安装后请完全重启 Devin。若 Devin 自带 Remote SSH 扩展报 `navigator is now a global in nodejs`，在 Devin 用户设置中配置 `"extensions.supportNodeGlobalNavigator": true` 并重启。

在 Devin 中将 Cascade 与 Devin Local 的模型请求按配置路由到 OpenAI 兼容或 Anthropic 原生 API 供应商。绑定的模型由本地网关完成路由与协议适配，未绑定的模型继续使用 Devin 官方服务。

## 主要能力

- 管理多个自定义 API 供应商、Base URL 和 API Key
- 分别配置 Cascade 与 Devin Local 的模型绑定
- 支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 协议
- 支持模型推理参数、上下文窗口、提示词缓存和视觉请求
- 保留 Devin 原生会话选模、上下文显示与历史压缩流程；Local 与 Cascade 桥接层默认均不预先二次裁剪，仅在明确的上游上下文超限且尚未输出时由 Local 压缩一次并重试（旧 Cascade 压缩仅通过 `BYOK_HISTORY_COMPRESS=1` 显式启用）
- 支持 Windows 本地环境以及 Linux Remote SSH 工作区
- 提供连接测试、运行状态、请求日志和崩溃诊断
- 支持安装 Devin Local 原生子代理配置，并可为已识别的默认子代理请求指定独立的 Local 模型绑定
- 子代理面板可按项目开启 MCP 工具；Playwright 首次开启时按需安装，不增加 VSIX 中的浏览器依赖体积

## 安装

### 1.1.33：Context7 开关

原生子代理面板的 MCP 工具列表新增 Context7。它使用官方远程端点 `https://mcp.context7.com/mcp`，开启时写入当前项目的 Devin MCP 配置，不下载本地 npm 包；关闭时将配置标记为 `disabled`。无 API Key 可使用基础服务；如需更高额度，可自行在本地 MCP 配置中添加授权头，开关会保留已有授权头。查询内容会发送到 Context7 服务。请在切换后新建 Devin 会话验证。

### 1.1.32：子代理 MCP 工具开关

原生子代理面板新增当前项目的 MCP 工具开关。首次开启 Playwright 时，插件检查 Node.js 18+ 和 Chrome/Edge，将固定版本的 `@playwright/mcp` 安装到用户数据目录，并写入当前项目的 `.devin/mcp_config.local.json`。再次开启复用已有安装；关闭时设置 `disabled`，保留文件供以后使用。新建 Devin 会话后可验证工具列表变化。插件包不包含 Playwright 依赖。

后续 MCP 工具可以在 `native-mcp.cjs` 的目录中扩展，面板会按目录显示开关。已有同名但不同的配置不会被覆盖。

### 1.1.31：修复默认子代理模型路由

Devin 当前版本的默认子代理会在系统提示中标识 `Subagent Default`，但实际模型请求可能使用 `swe-1-6-slow`。网关现在识别这个系统级标识并应用子代理专用绑定；普通 SWE 会话和用户消息中的相同文字不会触发专用路由。原有 `subagent-default` 内部 UID 路由保持有效。

### 1.1.30：修复子代理创建参数

Local 上游模型调用 `run_subagent` 时若把新建请求的 `resume` 填为空字符串或 `new`，网关会移除该占位值，避免 Devin 误判为恢复一个不存在的子代理。真正的恢复 ID 保持不变。

### 1.1.29：子代理模型选择

在原生子代理区块中按供应商筛选已绑定的 Local 模型，并直接在面板里保存 `subagent-default` 的路由。

### 1.1.28：原生执行优先

默认保留 Devin 自己的计划、待办状态、执行节奏、回复语言选择和终端工具调用。BYOK 继续提供模型路由、协议适配与传输兼容。先前的额外补救改为按需开启：`BYOK_LOCAL_RESPONSE_LANGUAGE_PROMPT=on`、`BYOK_LOCAL_EXECUTION_PROMPTS=on`、`BYOK_LOCAL_ACCEPTANCE_GUARD=on`、`BYOK_LOCAL_PROCESS_GUARD=on`。未设置时均不干预对应的 Devin 原生行为。

### 1.1.23：验收待办分类与重复调用修复

继承 1.1.22 的上游流处理。创建、编写浏览器测试等实现待办不再因标题含有“测试”而被当作验收；明确要求运行或验收的待办仍需通过证据。同一完成申请被拦截后，如无新的验证证据，网关停止重复发送待办工具调用并提示报告阻塞；有新结果时可重新判断。

### 1.1.24：重复调用拦截后的状态回报

重复验收待办调用被拦截时，最终回复列出实际待办状态与最近验证结果，避免模型只发出被拦截的工具调用而留下空白答复。

### 1.1.25：阶段实现待办分类

识别“阶段三：扩展页面表单…”及“阶段四：补充浏览器测试…”等实现待办，不再误当作持久化或浏览器验收；带有明确运行、验证动作的待办继续要求对应通过证据。

### 1.1.27：长任务探索阶段误判修复

“检查现有代码、存储结构与测试约定”等探索待办不再被误判为测试验收，避免后续重复待办调用截断实现过程。明确运行测试或检查测试结果仍需对应证据。

### 1.1.26：陈旧证据测试收尾

记录验证结果及清理探针不再被误判为验收；源码变更后，旧验证结果仍会失效。被拦截的待办之后注入继续执行提示，引导模型完成清理和重验，而不是重复发送相同待办。

### 1.1.21：验收与执行补救

1.1.21 曾默认检查 Local BYOK 验收待办：对应检查缺少可识别的通过结果时，模型提交的 `completed` 会保留为 `pending`，并在回答末尾说明未验收。1.1.28 起，此补救仅在 `BYOK_LOCAL_ACCEPTANCE_GUARD=on` 时启用。构建通过不能替代浏览器验收；测试必须有大于零的通过数量和退出码 0。失败、后台运行中、只打开预览地址或 0 项测试均不算通过。源码变更会使先前结果失效；仅更新 plan.md 等计划文件不会触发重测。

检查依据是当前会话的命令级结果，不证明测试覆盖全部需求。未识别的手工浏览器检查或自定义输出会保守地保持未验收；已有待办历史不会直接改写。模型原本的文字会保留，补救状态在回答末尾单独显示。该补救仅覆盖本地守护进程处理的 BYOK 响应，未绑定的官方请求和云中继路径不在此检查范围内。

显式开启 `BYOK_LOCAL_PROCESS_GUARD=on` 后，通用终端调用中的常见进程终止命令（如 Stop-Process、taskkill、pkill、killall、kill 和 os/process.kill）会在交给 Devin 前被拦截。这个检测不能替代系统沙箱，不能穷尽任意脚本、别名和所有系统操作。

1.1.28 起这些补救默认关闭；仅在复现对应问题时设置所需的 `...=on`。更新后重载 Devin 窗口，使新版扩展和本地守护进程加载。

1. 在 Devin 的扩展面板中卸载旧版本插件（如有）。
2. 打开扩展面板，选择 **Install from VSIX**。
3. 选择 Devin Model Gateway 的 VSIX 安装包并重载窗口。
4. 从左侧活动栏打开 **Devin Model Gateway** 控制面板。

不要将插件安装到其他编辑器，也不要与旧的独立 Local Probe 扩展同时运行，以免发生端口冲突。

## 快速开始

1. 在「供应商列表」中添加供应商，选择接口协议并填写名称、Base URL 和 API Key。
2. 在「Cascade 模型绑定」或「Local 模型绑定」中选择供应商和上游模型。
3. 启动对应代理。绑定的模型走自定义供应商，未绑定的模型继续走官方服务。

## 原生子代理

1. 在插件页面的 **Devin Local → 原生子代理** 区块点击 **安装配置**（也可在命令面板执行 **Devin Model Gateway: 安装原生子代理配置**）。扩展会将 `test-runner`（执行测试）和 `browser-qa`（浏览器验收）安装到 Devin 的用户级 `agents` 目录；已有内容不同的同名文件不会被覆盖。
2. 新建或恢复 Devin Local 会话，要求 Devin 使用 `test-runner` 或 `browser-qa` 子代理。子代理的创建、权限、前后台运行和结果回传仍由 Devin 原生处理。组织策略或 Devin 设置关闭子代理时，本扩展不会绕过该限制。浏览器验收需在当前会话中实际存在可用的浏览器工具，建议以前台模式运行以便批准工具调用。
3. 如需让默认子代理使用第三方模型，先在「Local 模型绑定」启用并绑定目标模型，再在 **原生子代理** 区块点击 **选择模型**，从面板中的下拉框选择供应商和该供应商的 Local 模型，最后点击 **保存**。选择「Devin 原生模型」可恢复默认路由。
4. 在同一区块的 **MCP 工具 · 当前项目** 打开 **浏览器工具 · Playwright**。首次开启会下载安装工具，之后新建 Devin 会话即可让 `browser-qa` 使用浏览器工具。关闭开关后，新会话不再加载该 MCP；已安装文件仍保留。
5. 需要核对框架或 SDK 的较新文档时，打开 **开发文档 · Context7**。它提供库名解析和文档查询两个远程工具，无本地安装步骤。

移除时点击 **移除配置**（也可执行 **Devin Model Gateway: 移除原生子代理配置**）。扩展只会删除与自带配置完全一致的文件；手动修改过的配置会保留，并提示你自行处理。

专用路由匹配请求的内部 UID `subagent-default`，或模型 UID 为 `swe-1-6-slow` 且系统提示明确标识 `Subagent Default` 的请求。其他请求按现有 Local 绑定处理；未绑定的 UID 保持 Devin 官方路由。专用绑定被删除、失效或配置损坏时会显示路由错误，不会悄悄透传到官方。路由文件位于 `config\subagentRouting.json`。

仓库中的 `extension/devin-plugin` 也可作为独立 Devin Plugin 安装，例如在仓库根目录运行 `devin plugins install --local ./extension/devin-plugin`。它提供同样的两个配置，安装后名称由 Devin 加上插件前缀；使用这种方式时无需再执行上面的配置安装命令。自定义子代理目前仅适用于本地 Devin CLI 和 Desktop。

### 验证

先运行只读子代理并在 Local 输出日志中查找 `[BYOK-SUBAGENT]`。`route=native` 表示交回 Devin；`route=bound` 表示命中专用绑定，`source` 表示内部 UID 或默认子代理系统标识。若没有此日志，检查 `[BYOK-IDENTITY]` 的 `wireUid`，确认 Devin 是否使用了尚未识别的请求格式。日志不包含提示词或 API Key。

## 本地图片

Devin Local 支持通过粘贴、拖放、选择文件或在消息中填写本地图片路径发送图片。支持 `jpg`、`jpeg`、`png`、`gif`、`webp` 和 `bmp`，单张图片不超过 15 MB。

模型绑定中的「视觉」选项默认开启。关闭后，网关会在发送请求前移除图片，避免不支持视觉能力的模型返回错误。

Local `read` 工具返回的图片也会按图片内容转发给视觉模型。网关在向自定义模型发送请求前，用本地 `sharp` 将大图缩至约 169 万像素以内，并优先编码为 WebP；长图按最多 6 块切分，保留文字可读性。Devin 会话中的原始图片不变，历史压缩仍由 Devin 原生流程负责。预处理可以用 `BYOK_LOCAL_IMAGE_PREPROCESS=off` 关闭。

Local 网关完整读取 `GetChatMessage` 请求，默认上限为 64 MiB，可通过 `BYOK_LOCAL_CHAT_BODY_MAX_MB` 在 8–128 MiB 范围调整。超限会明确返回 413，不再把截断的 protobuf 误报为 `no-proto-fields`。

## 任务连续性

Local 网关会读取 Devin 原生 `todo_write` 等计划工具中的未完成步骤，以及代码修改后的待验证状态，在下一次模型请求中加入通用的收尾提醒。补充要求和「继续」会保留当前计划；用户明确换任务或取消原任务时才清除旧提醒。

从 1.1.19 起，计划文件、批准、模式切换、执行待办和上下文压缩由 Devin 原生流程负责。插件不要求计划阶段与 todo 数量、标题或分组一致，不强制批准后再次 read。完成情况应按计划中的功能、约束及验收证据核对；现有通用收尾提醒不构成自动验收保证。

升级激活时自动备份 Devin 用户配置并移除本插件以前安装的阶段对齐 Hooks，同组中的其他用户 Hooks 保留。命令面板中的 **恢复原生计划流程** 可重试清理；旧安装命令也只执行清理，不会重新安装旧门槛。请新建会话确认生效，旧会话中已经注入的指令无法撤回。原生压缩默认优先转发官方；仅在上游明确拒绝上下文长度后，才允许网关执行一次裁剪重试。真实长任务还需验证压缩后的计划与验收信息保留情况。

## Remote SSH

插件主体运行在本地 UI 扩展宿主中。配置 SSH 主机后，插件会建立远端到本地网关的回环通道、复制本地 CA 公共证书，并同步 Devin Local 所需的 ACP 配置。

连接新 SSH 主机时，插件会在原生 Remote SSH 读取主机配置前写入该主机专用的回环转发，并为本次连接提供启动服务器所需的代理地址。请先启动本机 Local（6778）；服务器必须允许 TCP 转发。连接建立后，插件会同步远端证书与 ACP 配置；若远端扩展宿主已经启动，首次连接后可能还需重连一次以加载 Devin Local。修改端口后也需重新连接。可以通过命令面板中的以下命令管理配置：

- **Devin Model Gateway: 配置当前 SSH 主机**
- **Devin Model Gateway: 移除当前 SSH 主机配置**

### 源码中的适配验证工具

这些工具复用当前 Local 适配器，独立于正在运行的 Devin 会话。它们不增加原生 Agent 功能，也不会修改供应商绑定。现存 1.1.21 安装包不包含本轮新增工具；请在源码目录运行。

在 `extension` 目录执行 `npm run audit:native`，只读检查原生会话的活动消息链、选模和用量一致性，以及安装目录中的适配器是否匹配源码。报告不包含提示词、工具参数、工作区路径或原始会话 ID。安装文件匹配不等于已确认进程加载版本，数据库一致也不等于窗口显示或并发路由已验收。

执行 `npm run probe:capabilities -- <Local模型UID> --run` 可使用该绑定发送最多四次合成请求，检查流式正文、合法工具调用、多工具结果续接及测试图片识别。`--vision-only` 仅检查一次图片请求；`--out <文件路径>` 保存脱敏报告。只有显式指定 `--run` 才会调用供应商，按供应商计费；不执行返回的工具，不发送项目或会话内容。

结果中的 `verified` 表示本次指定检查通过，`accepted` 仅表示接口接受，`unconfirmed` 表示证据不足，`failed` 表示本次检查失败，`not-tested` 表示未测试。超时或上游错误不能直接证明模型不支持；推理参数被接受也不证明计算强度。报告不能作为原生 Agent 的端到端验收，暂不测试最大上下文和缓存命中率。

`npm run test:capabilities` 和 `npm run test:native-audit` 只使用本机模拟接口和临时数据库，不调用真实供应商。

## 常见问题

- **代理或补丁异常**：运行 **Devin Model Gateway: 安装补丁**，然后重载 Devin；也可以查看输出日志确认错误原因。
- **Local 无法启动**：检查 `6778` 端口是否被占用，查看 Local 输出日志，必要时执行完全停止 Local 后重新开启。
- **请求未走自定义供应商**：确认绑定中已经同时选择供应商和上游模型，并确认对应代理已开启。
- **API Key 错误**：重新编辑供应商并填写完整 Key，不要保存界面中显示的脱敏值。
- **模型列表为空**：先启动对应代理，在 Devin 中使用一次模型，然后刷新模型列表。
- **Devin 更新后补丁不兼容**：插件会停止写入不匹配的补丁。请等待适配新版本，不要强行修改 Devin 的程序文件。
