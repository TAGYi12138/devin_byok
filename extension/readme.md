# Devin Model Gateway 使用说明

本地插件 **1.1.50**，用于把 Devin 的 Cascade、Local 与代码补全请求接入自定义模型 API。[项目介绍与构建方法](../README.md)提供安装前的准备步骤。

## 配置供应商和模型

1. 打开侧边栏的 **Devin Model Gateway** 控制面板。
2. 添加供应商，填写供应商名称、Base URL 和 API Key。
3. 按实际接口选择 OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages。
4. 填写供应商支持的模型 ID，并设置视觉能力、上下文窗口和推理参数。
5. 在 Cascade 或 Local 模型绑定区域选择目标模型，启动对应代理。
6. 按面板提示完成原生适配和窗口重载，新建会话进行验证。

同一供应商可配置多个模型。未绑定的模型使用 Devin 官方服务；模型能力与可用参数以供应商实际接口为准。

## 代码补全

在 **代码补全** 区块开启功能，选择供应商、补全模型和最长等待时间，点击保存。供应商留空时自动选择已绑定模型；明确选择供应商时需要填写模型 ID。默认等待时间为 15000 毫秒，可设置为 100–30000 毫秒。

在编辑器中输入代码，等待行内建议出现。关闭此功能可恢复使用 Devin 官方补全。没有建议时，检查编辑器行内建议是否启用，以及供应商和模型是否可用。

## 原生模型菜单

插件根据 Devin 的版本、通道与实际代码结构选择适配规则。安装或更新后，按提示重新加载窗口；Remote SSH 工作区还需重新连接。

支持的具体构建、匹配原则和诊断方法见[原生模型菜单兼容说明](native-picker-compatibility.md)。升级 Devin 后若适配失败，请先查看兼容性诊断。

## Remote SSH

1. 在 Windows 本机启动 Local 网关。
2. 确保远端 SSH 服务允许 TCP 转发，再使用 Devin 的 Remote SSH 连接主机。
3. 插件准备回环转发，并同步远端所需证书和 ACP 配置。
4. 首次配置或调整端口后，按提示断开并重新连接。

默认端口如下：

| 服务 | 监听地址 |
| --- | --- |
| Cascade Hybrid | `127.0.0.1:6678` |
| Cascade Inference | `127.0.0.1:6688` |
| 本机 Local | `127.0.0.1:6778` |
| SSH 远端回环转发 | `127.0.0.1:16778` |

命令面板中可搜索“配置当前 SSH 主机”“移除当前 SSH 主机配置”，管理对应主机的设置。

## 子代理与 MCP

在 **Devin Local → 原生子代理** 区域安装配置，提供 `test-runner` 和 `browser-qa`。如需为默认子代理指定模型，先完成 Local 模型绑定，再在子代理区域选择并保存模型路由。子代理的创建、权限和运行仍由 Devin 处理。

**MCP 工具 · 当前项目** 可按项目启用工具。首次启用某些工具时会安装依赖；远程工具使用对应服务地址。切换后新建 Devin 会话，确认工具已经加载。浏览器验收需要会话中存在可用的浏览器工具。

## 图片与上下文

支持视觉的模型可接收 Local 图片输入。绑定中关闭视觉能力后，网关会移除图片。图片预处理使用安装包内的 `sharp`；设置 `BYOK_LOCAL_IMAGE_PREPROCESS=off` 可关闭预处理。

默认保留 Devin 原生历史与压缩流程。Local 上游明确拒绝上下文长度、且尚未产生输出或工具调用时，网关可执行一次压缩重试。

## 更新与排错

本地版通过重新安装 VSIX 更新，默认停用在线更新及图片运行库下载。

- **连接失败**：检查 Base URL、API 协议、Key、模型 ID 和供应商额度。
- **Local 无法启动**：检查 `6778` 端口占用，在命令面板查看 Local 输出；必要时完全停止 Local 后重新开启。
- **模型菜单异常**：查看兼容性诊断，确认当前 Devin 构建与适配规则匹配。
- **SSH 无法使用模型**：确认本机 Local 已启动、远端允许转发，并在配置同步后重新连接。
- **需要定位错误**：在命令面板搜索“显示输出日志”“显示 Local 输出日志”或“显示崩溃诊断日志”。
